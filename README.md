Calculator Project

Description

A simple and responsive calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

Features

- User-friendly interface
- Basic arithmetic operations
- Clear (C) button to reset the display
- Error handling for invalid expressions
- Responsive design

Technologies Used

- HTML
- CSS
- JavaScript

Project Structure

- index.html
- style.css
- script.js
- README.md

How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run "index.html" in your browser.
